# Versions

| Tag | Date | Highlights |
|---|---|---|
| `v0.3-plugin-package` | 2026-09-28 | First public release as an Omarchy plugin (`io.github.leoaba.sidecar`). Setup script, README, dependency list, MIT licence and preview image. Custom iPad icon, redesigned panel with a connected-device section, and an author credit link. |
| `v0.2-live-quality` | 2026-09-28 | Quality switches live while connected, via the panel or `omarchy-sidecar quality`. The virtual display always renders at native size and quality sets the encode scale. Rotation support. The pointer keeps its position across connect and disconnect. Quality choice applies on USB. Log capped at 2 MB. |
| `v0.1-wifi-usb-widget` | 2026-09-27 | First working release on a real iPad. Wi-Fi via Bonjour and USB-C via a built-in usbmuxd client, with automatic switching between them. H.264 streaming tuned for iPad hardware decoding. Touch input and a bar widget. |
